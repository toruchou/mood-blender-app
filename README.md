# Mood Blender

A cute mobile app built with React, TypeScript, and Vite. 

## What it does
Mood Blender is basically a cozy applet designed to mix and match different moods that you pick. You just click on your ingredients and it blends them together to give you a sweet, personalized description!

### Features
* Beautiful, custom pastel color palette
* Light mode and dark mode support
* Fully self-contained audio triggers using the native Web Audio API
* 100% offline local privacy; no data ever leaves your device

## Setup & Installation
To run the project locally, just run these standard commands in your terminal:

```bash
npm install

npm run build

npx cap add android
